# 📱 Ryan Cell - Landing Page

Landing page desenvolvida para a loja **Ryan Cell**, especializada em manutenção de celulares, computadores e videogames.

---

## 🚀 Sobre o projeto

Este projeto foi criado com o objetivo de apresentar os serviços da loja de forma clara, moderna e responsiva, facilitando o contato com clientes e aumentando a conversão.

A página destaca os principais serviços oferecidos, além de transmitir profissionalismo e confiança para os visitantes.

---

## 🎯 Objetivos

* Apresentar os serviços da loja
* Melhorar a presença digital
* Facilitar o contato com clientes
* Criar um layout moderno e responsivo

---

## 🛠️ Tecnologias utilizadas

* HTML5
* CSS3
* TypeScript
* React
* Lovable ia

---

## 💡 Funcionalidades

* Layout moderno inspirado em padrões atuais
* Totalmente responsivo (mobile, tablet e desktop)
* Seção de serviços
* Botão de contato rápido (WhatsApp)
* Navegação simples e intuitiva
